Latest change note: at 2026-08-07 16:10 Asia/Shanghai, Pixingyun Mate `3.2.48` completely eliminates the PowerShell window popup during updates. Root causes: (1) `CREATE_NO_WINDOW | DETACHED_PROCESS` is an invalid flag combination (Microsoft docs: incompatible), causing window leakage; (2) `cmd /c` always flashes a console window even with `CREATE_NO_WINDOW`; (3) `-WindowStyle Hidden` only takes effect AFTER PowerShell starts (brief flash); (4) `.exe` update path incorrectly used `/VERYSILENT /SUPPRESSMSGBOXES /NORESTART` (Inno Setup installer flags) on a PyInstaller portable exe. Fix: (1) Replaced CMD→PowerShell launcher with VBScript launcher — `wscript.exe` has no UI, VBScript `WshShell.Run …, 0, True` hides the window from the very first instruction; (2) Removed `DETACHED_PROCESS` flag, use only `CREATE_NO_WINDOW` + `STARTUPINFO(SW_HIDE)`; (3) Rewrote `.exe` update path as direct exe replacement (backup → copy → Unblock-File → restart), not installer mode; (4) Compatible with Windows 7/8/10/11 — VBScript is always available, no dependency on PowerShell execution policy.
